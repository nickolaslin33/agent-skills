# ask-like-a-pro — 問得像行家

你用 PM 的角色跟 AI 提需求時，它收到訊息會先檢查你的問法：有沒有漏掉會影響結果的資訊，有沒有「弄快一點」「優化一下」這種模糊用語。然後給你一版改寫，下次照著問就好。

**你可能會反對的三件事**：

- **有時候它會先停下來，不動手。** 缺口大到照猜的做很可能做錯方向（像不知道要給誰用、範圍完全沒講），它會先問你，確認完才做。小缺口就提醒一句、照原本的問法做完。
- **只安裝 skill 不會每次生效。** 要每次都生效得在 `CLAUDE.md` 加一段，做法見下一節。
- **不教你寫技術規格。** 它假設你是懂產品、有技術 sense 的 PM，會建議你講清楚限制和取捨，但不會要你指定用哪個函式庫、資料表怎麼設計。

## 兩種生效方式，只裝 skill 會漏

| 做法 | 行為 | 什麼時候會漏 |
|---|---|---|
| 只安裝 skill | **on-demand**：你打 `/ask-like-a-pro` 才一定生效，否則 Claude 讀 `description` 自己判斷 | 常漏。訊息看起來像單純的任務時，Claude 傾向直接做 |
| 安裝 skill ＋ `CLAUDE.md` 加一段 | **always-on**：每輪都會先檢查問法 | 幾乎不漏 |

要 always-on 的話，在 `CLAUDE.md` 加這段：

```markdown
## 提問檢查

我以 PM 的角色交代任務或提需求時，收到訊息就先照
`skills/ask-like-a-pro/SKILL.md` 的規則檢查問法。我沒有要求也要做。
```

## 它長什麼樣子

小缺口，提醒完照做：

```
— Ask like a pro —
· 目標跟對象：誰要用這份匯出？用途會決定欄位跟格式
· 範圍：全部會員，還是目前篩選後的結果？
改寫：「在會員列表加匯出 CSV 的按鈕，給〔營運〕每週對帳用，匯出〔目前篩選後〕的結果，欄位跟列表畫面一樣。」
這次我先假設是匯出篩選後的結果、CSV 格式，不對再跟我說。
```

`〔〕` 裡的是它猜的，換成你的真實答案就能直接用。

問法已經夠清楚、或你只是回「好」「繼續」的時候，這段整個不出現。
